# What should the packages be called on BendHub?

Type: grilling
Status: open
Blocked by: none
Map: [bend-http v1 spec](../map.md)

## Question

BendHub auctions names under 12 characters (opening bid at least 5 USD, 48 hours); names of 12+ characters are free. `urlpath` and `http1` would each need an auction. Choose: pay for the short names, use free longer ones (e.g. `bend-urlpath`, `http1-proven`), or publish by hash only. Names can't be re-pointed once used.
